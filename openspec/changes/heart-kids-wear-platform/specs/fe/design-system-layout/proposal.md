# Proposal: Design System Tokens & Global Layout (FE)

## Why
Heart Kids Wear requires a boutique aesthetic tailored for children's clothing with warm pastel and vibrant accent tokens, Google Fonts typography, responsive mobile-first grids, a universal header with quick navigation action icons, a persistent announcement banner, a footer with social links, and universal `NT$X,XXX` currency formatting.

## What Changes
- Custom Vanilla CSS design tokens (`index.css`).
- Currency formatting utility function (`formatCurrency` -> `NT$X,XXX`).
- Top announcement banner component.
- Global Header with logo, cart preview dropdown, wishlist, profile badge, and search.
- Global Footer with permanent FB, IG, and LINE community links.
- Floating "Chat with us!" live widget with conversation drawer.

## Impact
- Forms the visual foundation and global frame for all user and admin pages.
